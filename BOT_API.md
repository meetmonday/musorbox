# Musorgram Bot API

MusorBox предоставляет ограниченный интерфейс, совместимый с Telegram Bot API. Он нужен,
чтобы запускать существующих Telegram-ботов внутри личных и групповых чатов Musorgram.
Это не MTProto-сервер и не полная реализация Telegram.

## Создание и токены

Пользователь создаёт и управляет ботами на странице `/settings/bots`. Можно иметь не более
пяти ботов. Логин состоит из 3–32 латинских букв, цифр и `_` и должен оканчиваться на `bot`.
Логин после создания не меняется, отображаемое имя можно изменить.

Токен показывается только после создания, включения или замены. Сервер хранит его SHA-256-хеш.
Замена немедленно отзывает старый токен. Отключение отзывает токен, очищает ожидающие updates
и скрывает бота из поиска новых собеседников, но сохраняет пользователя, группы и историю.
При повторном включении выдаётся новый токен.

Отключённого бота можно удалить навсегда. Это освобождает место в квоте, но из-за модели
локальных пользователей также удаляет его личные диалоги и членство в группах; групповые
сообщения остаются с пометкой удалённого отправителя. Для временной остановки используйте
отключение, а не удаление.

Токен находится в URL по правилам Telegram Bot API. MusorBox редактирует его в собственных
HTTP-логах, но reverse proxy тоже должен скрывать сегмент после `/telegram-bot-api/bot`.
Не передавайте токен в query string, сообщения или репозиторий.

## Подключение

Базовый адрес имеет вид:

```text
https://example.org/telegram-bot-api/bot
```

GramIO:

```ts
const bot = new Bot(process.env.BOT_TOKEN!, {
  api: {
    baseURL: `${process.env.MUSORBOX_URL}/telegram-bot-api/bot`,
  },
});

bot.start();
```

Для `node-trashkek`:

```text
BOT_TOKEN=<токен со страницы настроек>
BOT_API_BASE_URL=https://example.org/telegram-bot-api/bot
```

Методы вызываются стандартно:

```text
POST /telegram-bot-api/bot<TOKEN>/getMe
POST /telegram-bot-api/bot<TOKEN>/getUpdates
POST /telegram-bot-api/bot<TOKEN>/sendMessage
```

Ответ имеет Telegram-форму `{ "ok": true, "result": ... }`. Ошибка содержит `ok: false`,
`error_code` и `description`. Параметры принимаются как JSON и как стандартный для Telegram
Bot API `application/x-www-form-urlencoded`.

## Поддерживаемые методы

### `getMe`

Возвращает локального пользователя бота. `can_read_all_group_messages` всегда `true`:
privacy mode сейчас отсутствует.

### `getUpdates`

Поддерживаются `offset` и `timeout` до 30 секунд. Updates хранятся в SQLite и переживают
перезапуск процесса. Значение `offset` подтверждает и удаляет более старые updates. Для одного
бота разрешён один одновременный long-poll запрос; второй получает `409`.

При отключении бота ожидающие updates удаляются. Webhook пока не поддерживается.

### `sendMessage`

Отправляет обычный текст до 4000 Unicode-символов. Telegram entities принимаются и возвращаются,
но Musorgram пока хранит и отображает только plain text. Inline-клавиатуры с HTTP(S)-ссылками и
`callback_data` хранятся и отображаются. Эффекты, link preview settings и `reply_parameters`
игнорируются.

Бот не может первым начать личный диалог: пользователь должен сначала написать ему. В группу бот
может отправлять сообщения только пока состоит в ней.

### `sendChatAction`

Возвращает `true`, но пока является no-op: клиенты Musorgram не показывают typing/upload status.

### `sendMediaGroup`

Поддерживаются только группы из 2–10 фотографий JPEG, PNG, WebP или GIF:

- публичные HTTPS URL;
- multipart-файлы через `attach://имя-поля`.

Лимиты: 20 МиБ на изображение, 50 МиБ на весь альбом, до 40 миллионов пикселей. Загрузка URL
имеет таймаут, ручную проверку редиректов и блокирует localhost, приватные и служебные IP.
Повторное использование Telegram `file_id` пока не поддерживается.

**Отличие модели:** Telegram представляет альбом несколькими Message с общим `media_group_id`,
а Musorgram хранит его одной записью с массивом изображений. В ответ Bot API возвращает массив
виртуальных Message с разными вычисляемыми `message_id`, но внутри Musorgram это одно сообщение.
В общий текст сохраняется первая непустая подпись. Дополнительные подписи возвращаются в ответе,
но не сохраняются как отдельные подписи изображений.

### `deleteMessage`

Удаляет сообщение из личного диалога бота или из группы, в которой бот состоит. В группе бот может
удалить любое сообщение — отдельной роли администратора для ботов в Musorgram пока нет.

### Callback и управление группой

Поддерживаются `answerCallbackQuery`, `editMessageReplyMarkup` и `getChatAdministrators`.
Нажатие `callback_data` создаёт обычный `callback_query` в очереди `getUpdates`; ответ бота
показывается пользователю. Единственным администратором, возвращаемым для группы, считается её
владелец.

`banChatMember` (и старый alias `kickChatMember`) отвечает `true` как совместимый no-op:
участник не удаляется и не блокируется.

## Формат updates и идентификаторы

Личные `chat.id` равны ID пользователя Musorgram. ID групп отрицательные и кодируются внутренним
адаптером. Бот не должен вычислять или сохранять смысл этой формулы: следует возвращать полученный
`message.chat.id` в методы отправки.

Сообщение, начинающееся с `/command` или `/command@bot`, получает entity `bot_command`, поэтому
обычные `bot.command(...)` библиотеки работают без изменений.

Боты получают все человеческие сообщения в группах, где состоят. Сообщения, отправленные ботами,
не доставляются другим ботам и обратно отправителю — это предотвращает циклы.

## Пока не поддерживается

- webhook;
- `sendPhoto` как отдельный метод;
- `getFile` и скачивание по `file_id`;
- видео, аудио, документы и animation;
- replies и редактирование текста сообщений;
- inline query;
- Telegram topics/threads, business messages и paid media;
- privacy mode и команды BotFather.

Неизвестный метод возвращает Telegram-совместимую ошибку `400`, а не перенаправляется во внешний
Telegram API.

## Логи и диагностика

События адаптера имеют префикс `[bot-api]`: авторизация, постановка update, доставка, отправка и
ошибки. Пустые long-poll запросы скрыты по умолчанию. Для подробного режима установите:

```text
BOT_API_DEBUG=1
```

Значения токенов, текст сообщений и полные media URL намеренно не записываются.
